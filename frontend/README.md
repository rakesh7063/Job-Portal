# Rojgar — Frontend (React + Vite)

This is the web UI for **Rojgar (Job Portal)**.

## Run locally

```bash
npm install
npm run dev
```

The dev server will print the local URL (commonly `http://localhost:5173`).

## Backend

Start the API from `../Backend` (Spring Boot). See the repository root `README.md` for the full setup and Docker instructions.
